# Forge Client

React UI for the website builder — chat with the API and preview the live sandbox in a mini browser.

## Setup

```bash
npm install
```

Copy `.env` if needed (`VITE_API_URL` defaults to `http://localhost:3000`).

## Run

Start the backend first, then:

```bash
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).
